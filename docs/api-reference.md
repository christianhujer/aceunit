# API Reference

Include one header:

```c
#include <aceunit.h>
```

## Types

### `aceunit_func_t`

```c
typedef void (*aceunit_func_t)(void);
```

Function pointer type used for test cases and lifecycle functions.

### `AceUnit_Fixture_t`

```c
typedef struct {
    const aceunit_func_t beforeAll;
    const aceunit_func_t afterAll;
    const aceunit_func_t beforeEach;
    const aceunit_func_t afterEach;
    const aceunit_func_t *testcases;
} AceUnit_Fixture_t;
```

Describes a single fixture (object file). Usually auto-generated by `aceunit`.

| Field | Description |
|-------|-------------|
| `beforeAll` | Called once before any test case; `NULL` if absent |
| `afterAll` | Called once after all test cases; `NULL` if absent |
| `beforeEach` | Called before each test case; `NULL` if absent |
| `afterEach` | Called after each test case; `NULL` if absent |
| `testcases` | NULL-terminated array of test case function pointers |

### `AceUnit_Result_t`

```c
typedef struct {
    int testCaseCount;
    int successCount;
    int failureCount;
} AceUnit_Result_t;
```

Accumulates results across one or more runs.

!!! note
    `AceUnit_run()` does **not** initialize `result`. Zero-initialize it before the first call so multiple runs can be collected into the same result.

## Functions

### `AceUnit_run()`

```c
void AceUnit_run(const AceUnit_Fixture_t *fixtures[], AceUnit_Result_t *result);
```

Runs all fixtures in `fixtures` and accumulates results into `*result`.

- `fixtures` — NULL-terminated array of fixture pointers; must not be `NULL`
- `result` — output; must not be `NULL`; must be initialized by caller

### `runCatching()`

```c
bool runCatching(void(*code)(void));
```

Calls `code`, catching failures according to the linked runner's implementation.

Returns `true` on success, `false` on failure. Implementations may also not return at all (e.g., SimpleRunner calling `abort()`).

### `AceUnit_fail()`

```c
void AceUnit_fail(void);
```

Fails and aborts the current test case. The mechanism depends on the linked runner:

| Runner | Mechanism |
|--------|-----------|
| Simple | `abort()` |
| SetJmp | `longjmp()` |
| Abort | `abort()` (caught via `SIGABRT` handler) |
| Fork | `abort()` (child process terminates) |

### `assert()`

```c
#define assert(cond)
```

Defined by `<aceunit.h>` if `<assert.h>` has not already defined it. Calls `AceUnit_fail()` when `cond` is false. On hosted environments, also prints the failing expression, file, and line to `stderr`.

## Globals

### `fixtures[]`

```c
extern const AceUnit_Fixture_t *fixtures[];
```

The global NULL-terminated fixture array, referenced by the generated `main()`. Auto-generated by `aceunit` and compiled from `testcases.c`.

## Entry Points

### `main()`

```c
int main(int argc, const char *argv[]);
```

Provided by the AceUnit library. Calls `AceUnit_run(fixtures, &result)` and prints a summary. Requires `fixtures` to be defined (by compiling the `aceunit`-generated `testcases.c`).

### `__wrap_main()`

```c
int __wrap_main(int argc, const char *argv[]);
```

Alternative entry point for programs that already have a `main()`. Link with `--wrap=main` (or `-Wl,--wrap=main`) to redirect `main` to `__wrap_main` while still keeping the original `main` accessible via `__real_main`.

```sh
cc *.o testcases.o -laceunit-fork -Wl,--wrap=main -o tests
```
